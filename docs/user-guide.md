# Kotorima（やることリマインダー）使い方

対象：Windows版 v1.0.0

Kotorimaは、思いついた用事を素早く登録し、期限・通知・メモを添えて整理するアプリです。AIを使わなくても、すべての基本機能を利用できます。

## 1. 最初の使い方

1. 配布ZIPを展開し、書き込み可能なフォルダーで `Kotorima.exe` を起動します。Windows 10/11とWebView2 Runtimeが必要です。
2. 上部の入力欄に用事を入力し、**Enter**で登録します。改行は**Shift＋Enter**です。
3. タスクの本文をクリックすると、詳細が開きます。メモ・期限・通知・カテゴリを編集し、**今すぐ保存**で反映します。
4. 用事を終えたら、一覧の完了ボタンを押します。完了済みは上部のチェックマークから確認できます。
5. メイン画面の**×**はトレイへの格納です。通知を受けるにはアプリを起動したままにします。完全終了はトレイアイコンの右クリックから行います。

## 2. タスクを追加・編集する

選択中のカテゴリに新しいタスクが入ります。「全て」の表示では、カテゴリ管理の先頭カテゴリが追加先です。定期だけの表示・完了済み・ごみ箱の表示中は通常の新規入力ができません。

- 入力欄の時計ボタンから、期限・通知・重要を付けて登録できます。
- よく使うタスク名は入力候補に表示されます。候補を選ばず、そのままEnterで登録することもできます。
- タスクを右クリックすると、詳細を開く・完了にする・ごみ箱へ送る操作を選べます。完了済みやごみ箱では、その状態に合う操作に変わります。

**詳細の変更は、保存するまで正式には反映されません。** 編集中に期限・通知を変更しても、保存前は新しい日時では動作しません。既に保存してある通知は引き続き有効です。

詳細の×や画面移動時に未保存の変更があれば、**保存して続ける／破棄して続ける／編集に戻る**を選べます。詳細下部の**変更を破棄**でも取り消せます。未保存の入力は下書きとして保持され、次に詳細を開いた際に復元されることがあります。保存失敗の表示が出た場合は、その画面に入力を残したまま原因を確認してください。

## 3. 今日やる・重要・期限・通知の違い

| 項目 | 使いどころ | 動作 |
| --- | --- | --- |
| 今日やる | 今日取り組む用事を選ぶ | タスクの日の出マークで切り替えます。期限は変わりません。 |
| 重要 | 優先したい用事に印を付ける | 一覧の★で切り替え、★の絞り込みで確認できます。 |
| 期限日 | いつまでに終えるかを管理する | 期限超過・今日・近日の表示に使います。期限だけでは個別通知しません。 |
| 通知 | 作業を思い出す日時を指定する | 指定日時に通知します。期限と別の日時を選べます。 |

「今日やる」「重要」などを組み合わせて絞り込めます。上部の期限帯やベルのボタンからは、期限が近いタスクを確認できます。検索は虫眼鏡から開きます。

## 4. カテゴリで整理する

カテゴリタブの**＋**、または**⋯ → カテゴリ管理**から追加できます。タブやリストのカテゴリ見出しを右クリックし、**カテゴリ編集**を選ぶこともできます。

- カテゴリ管理で名前・配色・表示順を変更できます。上下のボタンで表示順を入れ替えます。
- **表示**を外すと、そのカテゴリを非表示にします。通知と定期タスクの生成は続きます。先頭カテゴリは標準追加先なので非表示にできません。
- 通常一覧では、タスク左側の移動ハンドルをドラッグして順序やカテゴリを変更できます。詳細のカテゴリ欄からも変更できます。
- カテゴリを削除しても、タスクと定期設定は消えず、残った先頭カテゴリへ移動します。「未分類」という名前のカテゴリに固定ではありません。カテゴリは最低1個必要です。

## 5. メモ・画像・リンク

タスク詳細のメモ欄では、太字・文字色・画像・リンクを利用できます。画像は選択ボタンのほか、クリップボードからの貼り付けやドロップで追加できます。

画像をクリックすると、独立した画像ビューアで開きます。**×**または**Escape**で閉じます。Webページや作業フォルダーの参照先は、リンクとして登録できます。リンク先のファイルそのものをアプリへ取り込む機能ではありません。

通知でも手順や作業場所を見たい場合は、内容とメモの間にある**通知にメモを表示する**をオンにして保存します。初期値はオフです。通知内の画像・リンクを操作するだけでは、その通知を確認済みにはしません。設定の**通知内容を隠し、件数だけ表示**がオンの場合は、メモも隠します。

## 6. 通知が出たとき

詳細の**通知**欄で、期限日と同じ・明日・時間後・日時指定などを選びます。期限日と同じ場合は、期限日の通知時刻も指定します。

- **タスクの本文**をクリック：詳細を開き、その通知を閉じます。タスクは未完了のままです。
- **完了**：タスクを完了します。
- **10分後／あとで…**：選んだ時間後に再通知します。期限は変わりません。
- **×**：その通知を確認して閉じます。タスクは未完了のままです。

複数の通知は個別に表示されます。見逃した通知は**⋯ → 未確認の通知**で確認できます。画面に収まらない通知も、未確認の一覧に残ります。

設定でまとめ通知の時刻・曜日を指定すると、期限が近い用事をまとめて確認できます。まとめ通知では各タスクを完了でき、**ボードを開く**で一覧へ移れます。**⋯ → 通知を一時停止**で、通知を一時的に保留できます。

## 7. 定期タスクを使う

**⋯ → 定期設定**で、繰り返す用事を登録します。内容・カテゴリ・繰り返し周期・期限の曜日や日付・タスクリストへの追加日数を設定し、必要に応じて通知も指定します。

例：毎週金曜日が期限で、**タスクリストへの追加：2日前**なら、水曜日からその金曜日のタスクが追加対象になります。登録時も同じ条件で判定します。通知は別に、何日前の何時かを指定します。通知する日までにタスクが追加される設定にしてください。

- 周期ごとに別のタスクが作られます。前回分が未完了でも、次回分は追加されます。
- 定期由来のタスクは、カテゴリ一覧の**定期**で絞り込めます。
- 定期設定の一覧にある**自動追加**をオフにすると、次の生成を停止します。既に追加されたタスクは残ります。
- 再開時は、停止中に過ぎた期限の分をさかのぼって追加しません。
- 定期設定の編集は今後の生成分に適用され、既存のタスクは変わりません。作成済みの1件だけを直す場合は、そのタスクの詳細を編集します。

## 8. トレイとショートカット

- トレイアイコンを**シングルクリック**：簡易入力を開きます。入力してEnterで登録します。
- **ダブルクリック**：メイン画面を開きます。
- **右クリック**：アプリを終了できます。
- 初期設定の**Ctrl＋Alt＋N**：ほかのアプリから簡易入力を呼び出します。**⋯ → 設定**で変更・無効化できます。

ショートカットが登録できない場合は、ほかのアプリと重なっていない組み合わせへ変更してください。画面内のボタンの意味は、マウスを重ねると説明が出ます。

## 9. 完了済みとごみ箱

完了直後に表示される**元に戻す**で取り消せます。表示が消えた後でも、上部のチェックマークから完了済みを開き、未完了へ戻せます。

ごみ箱は**⋯ → ごみ箱**から開きます。タスクの右クリックなどから戻せます。完了済みとごみ箱では、該当タスクのあるカテゴリだけ表示します。

**完了済みをすべてごみ箱へ**は、検索結果だけでなく完了済み全件が対象です。**ごみ箱を空にする**は、ごみ箱のタスクを完全削除します。復元できなくなるため、残したい内容は先に戻すかバックアップしてください。残るタスク・定期設定が参照していない内部画像も整理されます。外部リンク先のファイルは削除しません。

## 10. 保存・バックアップ・引き継ぎ

タスク・設定・添付画像は、`Kotorima.exe` と同じ場所の **dataフォルダー**に保存します。アプリを移動する場合は、dataフォルダーも一緒に移動します。

**⋯ → 設定 → データとバックアップ**で、**画像を含めてバックアップ**を押すとZIPを保存します。保存先は画面に表示されます。**バックアップZIPから復元**で戻せます。復元は現在のタスク・設定をバックアップの内容へ戻す操作で、実行前に現在の内容もバックアップします。

MemoTodo v3から移る場合は、旧アプリをトレイから完全終了し、既存のdataフォルダーと同じ場所へKotorima.exeを配置してください。データや旧バックアップは引き継げます。APIキーはWindowsユーザー単位で暗号化され、バックアップには含まれません。別のPCへ移した場合は再入力してください。

## 11. AI入力補助は任意です

**⋯ → 設定 → AI対応**の**AIでタスク入力を補助する**で切り替えます。初期値はオフです。有効時は、カテゴリ・重要・期限・通知の候補や、似た既存タスクを入力中に表示します。推定を待たずに登録でき、手動で指定した項目は優先されます。

Jev、OpenAI互換API、同じPC上のローカルAIサーバーに接続できます。ローカルAIの環境構築やモデル配布はアプリに含みません。

入力中のタイトル・未完了タスク名・カテゴリ名を選んだ接続先に送信します。外部サービスを使用する場合は、送信してよい内容か確認してください。接続テストを含むクラウド通信は、サービスによって料金が発生します。

接続に失敗した場合、その起動中はAI通信を止め、通常登録に切り替えます。接続設定を確認し、**接続確認**に成功すると再開します。設定のオン・オフや接続先は**今すぐ保存**で反映します。APIキーの保存・削除はその場で反映します。

AIの推定精度は接続先のモデルに依存します。重要な期限や通知は、登録前に候補を確認してください。

## 困ったとき

- **通知が出ない**：アプリが起動中か、通知を一時停止していないか、タスクの通知日時を保存したか確認します。設定の**通知をテスト**は、保存済みの設定を使います。
- **画面を閉じても終了しない**：×はトレイへの格納です。完全終了はトレイアイコンの右クリックから行います。
- **移動後にデータが見えない**：Kotorima.exeと同じ場所に、元のdataフォルダーがあるか確認します。
- **リンクが開かない**：参照先が存在し、そのPCからアクセスできるか確認します。通知からWindowsのローカル／UNCパスを開く動作は、実機で未確認です。
