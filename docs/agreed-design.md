# Kotorima v3 合意仕様（2026-10-01 UI改修）

会話で修正・合意した最新仕様を基準とする。READMEはユーザー向けの概要・主要機能・定期タスクの簡単な説明・ライセンス・サポートに絞る。

- 旧UIを基礎にカテゴリごとの色付きリスト。常設サイドバーは置かない。
- タイトル入力・Enterで即登録。IME変換確定は登録しない。カテゴリ選択中はそのカテゴリへ追加。
- 左から「定期」「すべて」「各カテゴリ」。「すべて」は通常タスクのみ。除外チェックは置かない。
- カテゴリの色は背景・文字色の組。プリセット、カスタム登録、登録済み配色の管理を提供。カテゴリの管理は右側パネルで順序・表示・名前・配色を制御。
- カテゴリの休眠は表示だけの一時非表示。通知・定期生成・横断期限一覧は止めない。
- タスクの手動並べ替え・カテゴリ間移動・空カテゴリへの移動をD&Dで提供。
- 上部帯は期限超過・今日・近日の横断入口。対象が0件なら非表示。件数から一覧、タスクから詳細へ。ベルは期限順の一覧で、手動順を変えない。
- 上部はベル・…・×の小さなタイトルバー。最小化・最大化なし。×はトレイへ、終了はトレイの右クリック。ウィンドウサイズを記憶。最小幅360px。トレイのシングルクリックは入力だけの吹き出し、ダブルクリックはメイン表示。
- 完了済み・ごみ箱・カテゴリ管理・定期設定・設定は…メニューから開く。
- 説明は必要な入力ラベル以外をTIPへ。ホバー待ち時間は200ms。外側クリックでポップアップを閉じる。
- 通常・定期とも期限は日付のみでその日の終わり。通知は独立。期限到達だけでは個別通知しない。
- 定期ルールは期限の繰り返し、タスクリストへの追加日数、通知の日数・時刻を中心にする。初回期限日・期限時刻・強調開始・周期間隔の独立入力・終了日は置かない。
- 定期の追加日数は共通初期値7日前で新規作成時の入力初期値にのみ使用。各ルールに日数を保存し、共通値の変更は既存ルールに波及しない。個別変更可。登録時も残り0〜指定日数の周期分だけ追加。登録以前の過去分は追加しない。
- 定期生成後は永続カーソルで未稼働期間の各周期を拾い、未完了分を残して次周期を追加。重複生成しない。毎週・7日前なら期限当日に翌週分も追加。
- 自動追加のON/OFFは定期設定の一覧にトグルとして配置し、編集フォームには置かない。新規設定はON。停止時は追加停止、既存分は残す。再開は停止中の過去期限を補充せず今日以降へ。編集は今後の分へ適用し、既存分は変えない。
- 近日判定は共通設定に統一。追加日数・通知日数は暦日。通知がタスク追加より先の設定は保存不可。
- 個別通知は小さな独立ウィンドウを縦に並べる。常に最前面・タスクバーにアイコンを表示して点滅・フォーカスを奪わず操作まで保持。メイン非表示でも通知自身のアイコンを表示し、確認・完了で当該通知の点滅を停止する。新着を既存通知へ黙って差し替えない。
- 通知本文クリックで詳細へ移動し当該通知だけを確認して閉じる。操作は完了・10分後・あとで（30分〜1週間）。延期は通知のみで期限を変更しない。×は通知確認だけ、完了はタスク完了。画面に収まらない分も永続保持し、確認後に順次表示、全件一覧からも操作可能。
- 定時まとめ通知は大きめの独立ウィンドウ。行ごとの完了と「ボードを開く」を提供。「ボードを開く」は当該まとめだけを確認して閉じる。
- 詳細の編集はローカルの下書きとして保持し、期限・通知を含め「今すぐ保存」で正式に反映する。×や画面移動時に未保存の変更があれば、保存・破棄・編集に戻るを選べる。設定類は保存ボタンで確定して閉じる。保存ボタンは下部に常時表示・横幅いっぱい。
- メモは太字・文字色プリセット・画像・リンクを提供。画像選択・クリップボード画像貼り付け・ドロップ。編集欄高さを記憶。HTTP/HTTPS、ローカル・UNCの参照リンクを扱う。
- 新規アプリとしてexe横のdata/board.db・画像へ保存。旧版互換・旧データ移行は不要。既存の本アプリDBは破棄しない。

## 検証境界

Windowsネイティブのフォーカス・最前面・タスクバー・物理クリックはWindowsで検証する。Linuxのserverモードは業務ロジック・画面連携の検証であり、ネイティブ動作の代替にはならない。

## リリース後の操作改善

- 登録欄、カテゴリ、期限あり・重要・検索の順に配置。ソート選択は置かず、ベルから期限順、星から重要のみを確認。登録欄右の時計で登録前に期限・通知・重要を指定。
- 重要は各行の星で即時切替。詳細上部に完了ボタン。詳細外側クリックで保存して閉じる。詳細は上部帯を覆わない。
- 上部帯は超過・今日・近日ごとにタスク名を並べ、ホバーでクリック可能箇所を示す。
- …メニューをセパレータで整理し、ダークモードを配置。カテゴリ配色・メモ内の装飾色は維持する。
- 手動編集で定時まとめ通知を再評価しない。空だった定時枠も処理済みとして記録し、後から期限を入力して過去枠の通知が発生しないようにする。期限入力のみでは個別通知を生成しない。

## 確認後のUI整理

- 詳細上部に重要・ごみ箱・完了（完了済みなら再開）・保存して閉じるをアイコンで並べる。説明はTIPへ。
- 詳細は内容（タイトルとメモ）、期限・通知、カテゴリの順。メモの編集領域はリサイズした枠全体へ拡張する。
- メモの画像・リンク・取り消し操作はアイコン。見出し・箇条書き・チェックリストの作成操作と入力ショートカットを外す。既存文書内の構造は保持する。
- コピーしたパスの両端の二重引用符を除いてリンクを登録する。
- 期限帯はグループ単位で横並び。幅が足りないとグループごと折り返す。一覧のカテゴリ・検索・絞り込みの形、余白、選択表示を統一する。

- 保存状態は詳細ヘッダーのタイトル下に小さく表示する。下部の保存ボタンは横幅いっぱいに戻す。
