# アイコン

ユーザーが採用した「ミント色のベル鳥アイコン」を使用。画像編集で鳥の外側のみ透明化し、白い鳥の内部・緑の輪郭・目・ミント色の翼を維持しました。

編集指示：Remove only the pale outer background, preserve the approved bird/bell shape, proportions, green outline, eye, mint wing and white interior. Actual alpha transparency outside the complete silhouette. No redesign, text, added details or shadow.

Windows ICOはPNGから16・24・32・48・64・128・256pxを収録して作成。アプリ用PNGと実行ファイル用ICOはこのデザインを共用します。
