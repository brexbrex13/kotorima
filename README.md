# Kotorima（やることリマインダー）

思いついたことを付箋感覚で素早く登録できる、Windows向けのTodo・メモ・リマインダーアプリです。日々の作業から長期の目標、定例業務まで、カテゴリごとに整理して管理できます。

## ダウンロード・起動

[最新版のWindows版ZIP](https://github.com/brexbrex13/kotorima/releases/latest)を展開し、`Kotorima.exe`を起動してください。Windows 10/11とWebView2 Runtimeが必要です。書き込み可能なフォルダーで使用してください。

タスク・画像・設定は実行ファイル横の`data`フォルダーに保存します。MemoTodoから更新する場合は旧アプリをトレイから完全終了し、同じフォルダーに`Kotorima.exe`を配置してください。`data`フォルダーは削除しないでください。既存のバックアップも復元できます。

## マニュアル

[使い方](docs/user-guide.md)で基本操作を確認できます。配布ZIPには、ブラウザーで開けるオフライン版の`Manual.html`を同梱しています。

## 主な機能

- カテゴリ・色分け・並び替えによるタスク整理
- 期限管理と、期限が近いタスクの強調表示
- 期限に関係なく選べる「今日やる」一覧と、完了直後の取り消し
- よく登録するタスク名の入力候補
- （任意）Jev・OpenAI互換API（Geminiなど）・ローカルAIによる、タスク追加時のカテゴリ・重要・期限・通知の推定と、似たタスクの警告（入力中のタイトル・未完了タスク名・カテゴリ名を選択した接続先に送信します）
- 他のアプリからも呼び出せるタスク追加ショートカット（変更・無効化可能）
- 定期タスクの自動追加
- 独立した通知ウィンドウによるリマインダー・定時通知
- 文字装飾・画像・リンクに対応したメモ、独立した画像ビューア
- 通知にメモを表示する設定（初期値オフ）
- 編集内容の明示的な保存・破棄、完了済み／ごみ箱の一括整理
- バックアップ・復元

### 定期タスクについて

「定期設定」で繰り返す曜日や日付、何日前にタスクを追加するか、通知日時を設定します。追加されたタスクは指定カテゴリに入り、通常タスクと同じ一覧に表示されます。画面上部の「定期」で絞り込めます。

周期ごとに別のタスクが追加されます。完了しても次回分は予定どおり追加され、未完了の過去分も残ります。

定期設定の一覧にある「タスクの自動追加」トグルで、自動追加を一時停止・再開できます。停止しても追加済みのタスクは残ります。停止中に過ぎた期限の分は、再開しても追加されません。

### AI対応（任意）

設定画面の「データとバックアップ」の下にある「AI対応」で設定します。初期状態はオフです。

- **Jev**: TypeSafe・Vercel AI Gateway・Cloudflare Workers AI・TypeSafe互換のカスタム接続先。
- **OpenAI互換API**: OpenAI・Geminiなど。ベースURL（`/chat/completions` の手前まで）、利用可能なモデル名、APIキーを指定します。OpenAIとGeminiのURLを入力するボタンがあります。
- **ローカルAI**: 別途起動したLM Studio・OllamaなどのOpenAI互換サーバーに接続します。モデルを読み込み、サーバーに登録されたモデル名を指定してください。認証なしの場合はキー不要です。同じPCの `localhost`・`127.0.0.1`・`[::1]` が対象で、推論環境の構築やモデルの配布はアプリに含みません。

推定用プロンプトはアプリに内蔵しています。生成モデルの回答は候補と型を検査しますが、推定精度はモデルに依存し、Jevの確信度とは扱いが異なります。

接続状態は初回の推定通信で確認します。接続に失敗した場合、その起動中はAIへの通信を停止し、通常のタスク登録を続けます。設定の「接続確認」に成功するとAIを再開します。APIキーや接続設定を変更した場合も、次の入力で再試行できます。
入力中のタイトル・未完了タスク名・カテゴリ名を選択した接続先に送ります。キーはWindowsのユーザー単位で暗号化し、バックアップには含めません。OpenAI互換・ローカルAIのキーは接続先URLごとに分けて保存します。キーの保存・削除はその場で反映し、接続先・有効化・待ち時間は「今すぐ保存」で反映します。

「AIの待ち時間」は0で自動（Jevは1.5秒、OpenAI互換・ローカルAIは20秒）、1〜120秒で指定可能です。入力や登録はAIの返答を待ちません。接続テストは生成モデルでは小さな推論リクエストを送るため、クラウドでは料金が発生する場合があります。JSONモードに対応したChat Completionsモデルを使用してください。
