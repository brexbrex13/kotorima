# Kotorima（やることリマインダー）

思いついたことを付箋感覚で素早く登録できる、Windows向けのTodo・メモ・リマインダーアプリです。日々の作業から長期の目標、定例業務まで、カテゴリごとに整理して管理できます。

## ダウンロード・起動

[最新版のWindows版ZIP](https://github.com/brexbrex13/kotorima/releases/latest)を展開し、`Kotorima.exe`を起動してください。WebView2 Runtimeが必要です。書き込み可能なフォルダーで使用してください。

タスク・画像・設定は実行ファイル横の`data`フォルダーに保存します。

## 動作環境

- Windows 11（64ビット）
- WebView2 Runtime

## マニュアル

[使い方](docs/user-guide.md)で基本操作を確認できます。配布ZIPには、ブラウザーで開けるオフライン版の`Manual.html`を同梱しています。

## 主な機能

- カテゴリ・色分け・並び替えによるタスク整理
- 期限管理と、期限が近いタスクの強調表示
- 期限に関係なく選べる「今日やる」一覧と、完了直後の取り消し
- よく登録するタスク名の入力候補
- 他のアプリからも呼び出せるタスク追加ショートカット（変更・無効化可能）
- 定期タスクの自動追加
- 独立した通知ウィンドウによるリマインダー・定時通知
- 文字装飾・画像・リンクに対応したメモ、独立した画像ビューア
- 通知にメモを表示する設定（初期値オフ）
- 編集内容の明示的な保存・破棄、完了済み／ごみ箱の一括整理
- バックアップ・復元

### 定期タスクについて

「定期設定」で繰り返す曜日や日付、何日前にタスクを追加するか、通知日時を設定します。追加されたタスクは指定カテゴリに入り、通常タスクと同じ一覧に表示されます。画面上部の「定期」で絞り込めます。

周期ごとに別のタスクが追加されます。完了しても次回分は予定どおり追加され、未完了の過去分も残ります。

定期設定の一覧にある「タスクの自動追加」トグルで、自動追加を一時停止・再開できます。停止しても追加済みのタスクは残ります。停止中に過ぎた期限の分は、再開しても追加されません。
